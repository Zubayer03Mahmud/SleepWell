# SleepWell & Wellness App

## SleepWell.apk files are here : [SleepWell.apk](https://drive.google.com/drive/folders/1FwGS3iRPGwEkZGo0-HCXra1bzEtbhfAc?usp=drive_link)

A modern Android wellness application designed to help users track, understand, and improve their sleep habits.

## Overview

SleepWell is a Kotlin-based mobile app built with Jetpack Compose and Firebase. It helps users monitor their sleep patterns, view analytics, receive recommendations, and stay consistent with healthy routines.

## ✨ Features
- 🔐 Authentication — User registration, login, logout, and password reset.

- 👤 User Profile — Manage personal information such as name, email, gender, and age.

- 😴 Sleep Tracking — Record sleep and wake-up times, duration, quality, and related factors.

- 📊 Sleep Analytics — View sleep history, trends, duration, and personalized statistics.

- 🤖 AI Sleep Analysis — Get insights based on recorded sleep information.

- 💡 Recommendations — Receive useful tips for healthier sleep habits.

- 💬 Chat — Sleep and wellness assistance through the in-app chat interface.

## Getting Started

### Prerequisites

- Android Studio
- JDK 11 or newer
- Android SDK
- Firebase project setup

### Run the App

1. Clone the repository.
git clone https://github.com/Zubayer03Mahmud/SleepWell.git

Navigate to the Project:
    cd SleepWell

2. Open the project in Android Studio.
3. Sync Gradle files.
4. Connect Firebase if required.
5. Run the app on an emulator or physical Android device.
